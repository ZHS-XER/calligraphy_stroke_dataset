任务：识别单帧书法图像中的汉字（该帧信息已足够唯一确定该字）。

上下文：
- 本图像为汉字书法教学视频的截图。
- 当前帧包含足以判断目标汉字的关键笔画与结构。
- 此时还剩 {x} 个笔画没有写完；你必须在给出答案前，逐步预测这 {x} 笔的“下一笔/余下笔画”。
- 每一步须明确指出该笔画的“类别、相对位置、走向/结构关系”，并给出简短依据；链长必须严格等于 {x}。

输出规范（务必严格遵守）：
- 只输出一个 JSON 对象，且不包含任何多余文字、换行前缀或注释。
- 字段与取值：
  "chain": [                                      // 语言化逐步预测链，长度必须为 {x}
    {
      "step": 1,
      "stroke": "<笔画名称>",                      // 例如 "横" / "竖" / "撇" / "横折" / "钩" 等
      "position": "<相对位置>",                    // 例如 "左上/中部/右下/偏左/偏上/中心轴右侧" 等
      "direction": "<走向或结构关系>",              // 例如 "自左向右略上扬" / "自上而下穿过中轴" / "与左部竖相连成‘口’的下边"
      "evidence": "<为何此步应当补此笔>"
    },
    {
      "step": 2,
      "stroke": "<笔画名称>",
      "position": "<相对位置>",
      "direction": "<走向或结构关系>",
      "evidence": "<简要依据>"
    }
    // ... 直到 step = {x}
  ],
  "answer": "<单个汉字>",                           // 最终判定（必须与 probabilities[0].char 一致）
  "probabilities": [                                // 按概率降序，长度 3
    {"char":"<汉字1>","p":0.xx},
    {"char":"<汉字2>","p":0.xx},
    {"char":"<汉字3>","p":0.xx}
  ],
  "rationale": "<综合推断依据：当前帧可见结构 + 逐步补全链如何导向最终字形>"

严格格式要求：
- "chain" 的长度必须等于 {x}；step 从 1 递增，无缺号、无重复。
- 每个 step 必须给出 stroke、position、direction、evidence；均为短句，避免含糊词（如“可能”、“大概”），如需表达不确定，请在 evidence 中说明依据不足之处。
- 概率 p 为 0–1 之间的小数，保留两位；所有 p 之和必须等于 1.00（四舍五入后）。
- 若 "answer" ≠ probabilities[0].char，则令 "answer" = probabilities[0].char。
- 若可能的汉字数 < 3，用 null 代替汉字，概率用 0.00 填充。
- 仅可输出单个中文汉字作为候选，不得输出词语、拼音或符号。
- 不得输出除该 JSON 之外的任何字符（包括解释性文字、前后缀、Markdown 标记等）。

校准指引（内部执行，最终仅输出 JSON）：
- 逐步预测时，应保证链内结构一致：后续笔画不得与已预测的结构矛盾（如闭合口字后再补内向延长的横）。
- 优先选择能闭合部件或完成关键结构（如“口”“日”“门”）的笔画；若存在部件级先验，请在 evidence 中指明对应部件。
- 先为 Top-K 候选分配相对打分 s_i ∈ {1..9}，再归一化为 p_i = s_i / Σ s_i；若最高概率 < 0.50，仍需输出最可能答案。
- 在 "rationale" 中总结：哪几步是判定分歧的关键；语言链与可见笔画如何互相印证。
