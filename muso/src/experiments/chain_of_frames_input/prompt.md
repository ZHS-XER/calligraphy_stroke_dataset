任务：识别一组连续书法帧图像中的目标汉字（最后一帧信息已足够唯一确定该字）。

- 这些图像来自汉字书法教学视频，展示同一汉字的逐笔书写过程。
- 模型将获得若干前序帧，这些帧按书写时间顺序排列，且大致等间隔采样。
- 每一帧依次增加新的笔画，前序帧提供目标帧的书写上下文。
- 最后一帧（即链中最新一帧）包含足以判断目标汉字的全部关键信息。
- 当前帧（即最后一帧）仍剩余 {x} 个笔画尚未完成。

输出规范（务必严格遵守）：
- 只输出一个 JSON 对象，且不包含任何多余文字、换行前缀或注释。
- 字段与取值：
  "answer": "<单个汉字>",                       // 最终判定（必须与概率列表首项一致）
  "probabilities": [                            // 按概率降序，长度 3
    {{"char":"<汉字1>","p":0.xx}},
    {{"char":"<汉字2>","p":0.xx}},
    {{"char":"<汉字3>","p":0.xx}}
  ],
  "rationale": "<推断依据>"

严格格式要求：
- 概率 p 为 0–1 之间的小数，保留两位；所有 p 之和必须等于 1.00（四舍五入后）。
- 若 "answer" ≠ probabilities[0].char，则令 "answer" = probabilities[0].char。
- 若可能的汉字数 < 3，用 null 代替汉字，概率则用 0.00 填充。
- 仅可输出中文汉字作为候选，不得输出词语、拼音或符号。

校准指引（内部执行，最终仅输出 JSON）：
- 先为 Top-K 候选分配相对打分 s_i ∈ {{1..9}}，再归一化为概率 p_i = s_i / Σ s_i。
- 若最高概率 < 0.50，仍给出最可能答案。
- 在 "rationale" 中简述推断依据以及前序帧中哪些信息帮助模型确定该字（例如部首形状、结构补全或笔画趋势）。
