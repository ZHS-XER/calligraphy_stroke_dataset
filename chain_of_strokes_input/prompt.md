任务：识别单帧书法图像中的目标汉字（当前帧信息不足以唯一确定该字），但模型将同时获得该字的前序笔画语言链条（language stroke chain）作为辅助。

上下文：
- 图像来自汉字书法教学视频，展示目标汉字在某一笔未完成时的状态。
- 模型将获得一个按书写顺序排列的笔画名称序列（如 ["横","竖","撇"]），表示当前帧之前已完成的所有笔画。
- 该语言链条描述了书写的时间进程，可作为时序上下文辅助视觉推断。
- 当前帧中笔画尚未完全书写完毕，仍剩余 {x} 个笔画未完成。
- 模型需综合视觉信息与笔画语言链条，共同判断最终汉字。

输出规范（务必严格遵守）：
- 只输出一个 JSON 对象，且不包含任何多余文字、换行前缀或注释。
- 字段与取值：
  "answer": "<单个汉字>",                       // 最终判定（必须与概率列表首项一致）
  "probabilities": [                            // 按概率降序，长度 3
    {{"char":"<汉字1>","p":0.xx}},
    {{"char":"<汉字2>","p":0.xx}},
    {{"char":"<汉字3>","p":0.xx}}
  ],
  "rationale": "<推断依据>"

严格格式要求：
- 概率 p 为 0–1 之间的小数，保留两位；所有 p 之和必须等于 1.00（四舍五入后）。
- 若 "answer" ≠ probabilities[0].char，则令 "answer" = probabilities[0].char。
- 若可能的汉字数 < 3，用 null 代替汉字，概率则用 0.00 填充。
- 仅可输出中文汉字作为候选，不得输出词语、拼音或符号。

校准指引（内部执行，最终仅输出 JSON）：
- 先为 Top-K 候选分配相对打分 s_i ∈ {{1..9}}，再归一化为概率 p_i = s_i / Σ s_i。
- 若最高概率 < 0.50，仍给出最可能答案。
- 在 "rationale" 中简述推断依据，尤其说明语言链条中的哪些笔画信息帮助模型推断该字（例如部首走势、结构模式或与当前笔画的衔接趋势）。
